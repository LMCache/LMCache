# LMCache Documentation

Check out the [online doc](https://docs.lmcache.ai/developer_guide/contributing.html#building-the-docs) on how to build docs locally.

## Multilingual Support

This documentation supports multiple languages:
- **English** - Primary version
- **中文 (Chinese)** - Complete translation available

For translation maintenance, see [TRANSLATION_MAINTENANCE_zh.md](./TRANSLATION_MAINTENANCE_zh.md).

## Quick Build Commands

```bash
# Build English docs
make html

# Build Chinese docs  
make html-zh

# Build both languages
make html-all
```
