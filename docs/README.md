# LMCache Documentation

## 🌐 Online Documentation

### Access URLs

| Language | Main URL | Alternative URLs |
|----------|----------|------------------|
| **English** 🇺🇸 | https://docs.lmcache.ai/ | - |
| **中文** 🇨🇳 | https://docs.lmcache.ai/zh_CN/ | /zh/ or /cn/ |

```bash

make html-zh

# Build both languages
make html-all
```
