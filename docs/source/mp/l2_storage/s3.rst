S3
==

An L2 adapter that stores KV cache objects as S3 objects using the AWS
Common Runtime (CRT).  Works with AWS S3, S3 Express One Zone, and any
S3-compatible endpoint (MinIO, Ceph RGW, etc.).

**Required fields:**

Choose one addressing mode:

- ``s3_endpoint``: Legacy virtual-hosted bucket endpoint, either
  ``"s3://<bucket>.<host>"`` or ``"<bucket>.<host>"``. Requests use this
  host and ``/<object-key>``; existing configurations are unchanged.
- ``s3_endpoint_url`` and ``s3_bucket``: Path-style endpoint URL and separate
  bucket. Both are required together and are mutually exclusive with
  ``s3_endpoint``. The URL includes ``http://`` or ``https://``, an optional
  port, and an optional base path. For example,
  ``http://proxy.local:39999/api/v1/s3/`` with bucket ``kvbench-demo`` routes
  objects to ``/api/v1/s3/kvbench-demo/<object-key>`` and listings to
  ``/api/v1/s3/kvbench-demo/?list-type=2&...``. The complete host (including
  port), path and query are constructed before SigV4 signing.

URLs and bucket names must be unescaped: percent-encoded base paths/buckets,
userinfo, query strings, fragments, and dot path segments are rejected.
Object names retain the shared ObjectKey codec, including model slashes,
rank, group, hash, salt and identity tags; transport escaping is applied once.
The URL scheme controls TLS in path-style mode; ``disable_tls=true`` conflicts
with an HTTPS URL.
- ``s3_region``: AWS region string (e.g. ``"us-west-2"``).

**Optional fields:**

- ``s3_num_io_threads`` (int, default ``64``): Number of CRT I/O threads.
- ``s3_prefer_http2`` (bool, default ``true``): Negotiate HTTP/2 via ALPN.
- ``s3_enable_s3express`` (bool, default ``false``): Enable S3 Express signing
  for S3 Express One Zone buckets.
- ``disable_tls`` (bool, default ``false``): Bypass TLS when pointing at a
  plain-HTTP endpoint in legacy mode (e.g. a local MinIO).
- ``aws_access_key_id`` / ``aws_secret_access_key`` (string): Static
  credentials; omit both to use the AWS default credential provider chain
  (environment, EC2 instance profile, etc.).
- ``max_capacity_gb`` (float, default ``0.0``): Aggregate capacity used by
  ``get_usage()``.  A value of ``0`` disables aggregate eviction
  (``usage_fraction == -1.0``).

**Object sizes:**

A load succeeds only when the stored object is exactly the size of the
destination buffer.  A larger object is refused before any byte is copied
and a shorter one is reported as a miss; in both cases the engine
recomputes the chunk, and the object on S3 is not modified.  Custom serdes
whose ``estimate_serialized_size`` exceeds their actual output will
therefore miss on every load through this adapter.

**Configuration examples:**

.. code-block:: bash

    # AWS S3 with default credentials
    --l2-adapter '{"type": "s3", "s3_endpoint": "s3://my-bucket", "s3_region": "us-west-2"}'

    # Static credentials, HTTP/2 disabled
    --l2-adapter '{"type": "s3", "s3_endpoint": "s3://my-bucket", "s3_region": "us-west-2", "s3_prefer_http2": false, "aws_access_key_id": "AKIA...", "aws_secret_access_key": "..."}'

    # Local MinIO over plain HTTP
    --l2-adapter '{"type": "s3", "s3_endpoint": "minio.local:9000", "s3_region": "us-east-1", "disable_tls": true, "aws_access_key_id": "minio", "aws_secret_access_key": "minio123"}'

    # Path-style S3-compatible service; provision the bucket separately
    --l2-adapter '{"type": "s3", "s3_endpoint_url": "http://proxy.local:39999/api/v1/s3/", "s3_bucket": "kvbench-demo", "s3_region": "us-east-1", "s3_prefer_http2": false}'
