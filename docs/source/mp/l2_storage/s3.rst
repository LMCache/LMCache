S3
==

An L2 adapter that stores KV cache objects as S3 objects using the AWS
Common Runtime (CRT).  Works with AWS S3, S3 Express One Zone, and any
S3-compatible endpoint (MinIO, Ceph RGW, etc.) that accepts virtual-hosted
style requests.

**Required fields:**

- ``s3_endpoint``: Virtual-hosted bucket host -- either
  ``"s3://<bucket>.<host>"`` or the bare ``"<bucket>.<host>"`` form (e.g.
  ``"s3://my-bucket.s3.us-west-2.amazonaws.com"``).  The value is sent as the
  ``Host`` header of every request, so it must include the bucket name;
  path-style addressing (bucket in the URL path) is not supported.
- ``s3_region``: Region used for SigV4 signing (e.g. ``"us-west-2"``).  For
  an S3-compatible service, use the region of its endpoint.

**Optional fields:**

- ``s3_num_io_threads`` (int, default ``64``): Number of CRT I/O threads.
- ``s3_prefer_http2`` (bool, default ``true``): Negotiate HTTP/2 via ALPN.
- ``s3_enable_s3express`` (bool, default ``false``): Enable S3 Express signing
  for S3 Express One Zone buckets.
- ``disable_tls`` (bool, default ``false``): Bypass TLS when pointing at a
  plain-HTTP endpoint (e.g. a local MinIO).
- ``aws_access_key_id`` / ``aws_secret_access_key`` (string): Static
  credentials; omit both to use the AWS default credential provider chain
  (environment, EC2 instance profile, etc.).
- ``max_capacity_gb`` (float, default ``0.0``): Aggregate capacity used by
  ``get_usage()``.  A value of ``0`` disables aggregate eviction
  (``usage_fraction == -1.0``).

**Object sizes:**

A load succeeds only when the stored object is exactly the size of the
destination buffer.  A larger object is refused before any byte is copied
and a shorter one is reported as a miss; in both cases the engine
recomputes the chunk, and the object on S3 is not modified.  Custom serdes
whose ``estimate_serialized_size`` exceeds their actual output will
therefore miss on every load through this adapter.

**Configuration examples:**

.. code-block:: bash

    # AWS S3 with default credentials
    --l2-adapter '{"type": "s3", "s3_endpoint": "s3://my-bucket.s3.us-west-2.amazonaws.com", "s3_region": "us-west-2"}'

    # Static credentials, HTTP/2 disabled
    --l2-adapter '{"type": "s3", "s3_endpoint": "s3://my-bucket.s3.us-west-2.amazonaws.com", "s3_region": "us-west-2", "s3_prefer_http2": false, "aws_access_key_id": "AKIA...", "aws_secret_access_key": "..."}'

    # S3-compatible service over HTTPS (placeholder endpoint and region)
    --l2-adapter '{"type": "s3", "s3_endpoint": "s3://my-bucket.s3.example-region.example.com", "s3_region": "example-region", "aws_access_key_id": "<access-key-id>", "aws_secret_access_key": "<secret-access-key>"}'

    # Local MinIO over plain HTTP (MinIO must serve virtual-hosted requests,
    # i.e. MINIO_DOMAIN is set and <bucket>.minio.local resolves to it)
    --l2-adapter '{"type": "s3", "s3_endpoint": "my-bucket.minio.local:9000", "s3_region": "us-east-1", "disable_tls": true, "aws_access_key_id": "minio", "aws_secret_access_key": "minio123"}'
