Custom Storage Backends
=======================

.. warning::

   This page uses the deprecated in-process storage backend interface.
   For current storage adapters, see :doc:`/mp/l2_storage/index`.

LMCache supports integrating custom storage backends through dynamic loading or plug and play capability. This allows extending cache storage capabilities without modifying core code.

See :doc:`Storage Plugins </legacy/developer_guide/extending_lmcache/storage_plugins>` for more details.
