# Documentation Translations

This directory stores Sphinx/gettext translation catalogs. English `.rst` files
under `docs/source/` remain the source of truth.

## Directory Layout

- `zh_CN/`: Simplified Chinese translations.
- `LC_MESSAGES/`: Standard gettext catalog directory.
- `.po`: Reviewable translation files generated/updated by `sphinx-intl`.
- `.mo`: Compiled build artifacts generated by Sphinx. Do not commit these.

## Translation Flow

```text
1. English .rst files
      |
      | sphinx-build -b gettext
      v
2. .pot template files(disregarded and never commit)
      |
      | sphinx-intl update
      v
3. Chinese .po files with empty or fuzzy msgstr values
      |
      | python tools/translate_docs_zh.py
      | calls the translation endpoint
      v
4. Chinese .po files with translated msgstr values
      |
      | SPHINX_LANGUAGE=zh_CN sphinx-build -b html
      v
5. Chinese HTML
```

The actual model translation happens in `tools/translate_docs_zh.py`, after
`sphinx-intl` has created or updated the `.po` files. The scheduled GitHub
workflow that runs the process is `.github/workflows/translate_doc_zh.yml`.

To change the translation prompt, edit the system message in
`tools/translate_docs_zh.py`.

This README is for maintainers only. It is not linked from the Sphinx toctree,
so it should not appear on the public documentation website.
