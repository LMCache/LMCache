Attention
=========

.. meta::
   :description: Attention is the mechanism that lets each token in a sequence draw information from the other tokens around it.
   :keywords: Attention, attention mechanism, self-attention

**Attention is the mechanism that lets each token in a sequence draw information from the other tokens around it.**

To predict what comes next, a model needs more than the latest token in isolation; it needs the context before it.
In "The cat sat down because it was tired," the information associated with "cat" is what makes "it" meaningful.
Attention gives the model a way to compare the current token against earlier ones and blend in whatever matters for this step.

This happens at every layer, not just for obvious references like pronouns, and different attention heads learn to emphasize different relationships, such as nearby syntax, long-range references, and formatting patterns.

Attention is the reason a KV cache exists at all.
Because each token must look back over everything before it, the model needs the earlier tokens' intermediate state available at every step, which makes that state worth keeping.
