LMCache
=======

.. meta::
   :description: LMCache is an open source KV cache layer for LLM serving.
   :keywords: LMCache, LM Cache

**LMCache is an open source KV cache layer for LLM serving.**
It treats the KV cache as reusable data that can live beyond a single GPU-memory allocation and, when useful, beyond a single request or inference-engine process.

It moves KV data through a storage hierarchy spanning GPU memory, CPU memory, local storage, and remote backends, so that when a later request reuses cached context the serving system can retrieve the corresponding state rather than rebuilding it through prefill.
That can cut repeated computation, improve time to first token, and leave GPU memory free for active work.

LMCache integrates with the inference engine rather than replacing it — most commonly vLLM, through vLLM's KV connector interface.
It also includes integrations for SGLang and TensorRT-LLM.
