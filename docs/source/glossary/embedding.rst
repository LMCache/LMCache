Embedding
=========

.. meta::
   :description: An embedding is the vector — a list of numbers — that represents a token inside the model.
   :keywords: Embedding, embeddings, embedding vector, vector

**An embedding is the vector — a list of numbers — that represents a token inside the model.**
A model cannot multiply words, so every token is first converted into a fixed-length list of learned values it can operate on.

The mapping is built so that related tokens land near each other in that space.
"Cat" and "dog" end up close together; "cat" and "car" do not, despite looking similar as text.

The initial embedding is only a starting point.
As the vector passes through the model's layers, its representation shifts based on surrounding context.
For example, the token "bank" contributes differently in "river bank" than in "bank account."
The mechanism that lets one token take on information from others is :doc:`attention <attention>`.
