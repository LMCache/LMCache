# Acknowledgments

LMCache credits every contributor by GitHub handle, in
[CONTRIBUTORS.md](CONTRIBUTORS.md) and in the release notes. This file is for
contributors who want to be credited with more than a handle: a name, an
affiliation, or both.

## Rules

- Add, change, or remove only your own row, in a pull request opened from your
  own GitHub account. That pull request is your consent.
- Only the handle is required. If you leave the affiliation empty, release
  notes will not list one for you.
- Your affiliation is whatever you want to be credited with: an employer, a
  university, a lab, a project, or "Independent".
- You can change or remove your row at any time. Release notes published after
  the change use your new row.
- Maintainers never add, edit, or guess a row for anyone, whether from email
  domains, GitHub profiles, or other sources. The only exception is removing a
  row on the request of the person it describes.
- Keep rows in alphabetical order by handle. Dates use the YYYY-MM-DD format.

## Where the first rows came from

The first rows in this file copy the names and affiliations that committers
had already published in [MAINTAINERS.md](MAINTAINERS.md). Committers, please
check your row and change or remove it if it is not how you want to be
credited.

## How release notes use this file

When preparing a release, the release manager runs:

```bash
python tools/update_contributors.py thanks <previous-tag> <new-tag>
```

This prints a "Thanks" section for the release notes, with one line per
contributor in alphabetical order by GitHub handle. If you have a row in this
file, your name and affiliation follow your handle.
